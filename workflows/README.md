# Flujo exportado

`p01-validacion-api.json` es una copia sin modificaciones del flujo real exportado por María Duque. Contiene Manual Trigger, HTTP Request y Validar respuesta; la URL quedó restaurada a https://jsonplaceholder.typicode.com/posts/1.

Para importarlo, abrir un flujo en n8n y usar el menú de tres puntos → Import from File. Después ejecutar Execute Workflow y comprobar tres PASS en Validar respuesta.

La configuración y el código se revisaron. No se ha realizado una prueba independiente de importación en n8n.
